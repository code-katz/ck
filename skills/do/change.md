# /ck:do: a change to a step that came back

Send the same agent, with SendMessage (load that tool first when it is not loaded), the author's words and what you saw that bears on them, such as a failing command and its last lines. Say "Sent to `<persona>`. I'll tell you when it is back." and wait.

When it is back: for a mockup, read the file, publish it again from the same path, and say "Updated: `<link>`. OK?"; for a build, run the look back and report again.

When SendMessage fails: for a mockup, start a new agent with the file's path and the change. For a build, say the builder cannot be reached and ask "Discard and build again, or keep the branch as it is?"
