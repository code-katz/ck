# Sort a memory

Used by the memory gate and step 4 of /ck:claude-md. Give the memory one answer:

- **Keep**: a fact or a how-to a session looks up when it needs it, such as where a tool lives or a trap on this machine.
- **Retire**: a memory, a line of CLAUDE.md, or the "How we work" section already says it. Name where.
- **Move**: a rule a session must know from the start, which belongs in a file.
- **Disagree**: a memory or a line of CLAUDE.md says the opposite. Name both; the User picks which stands.

Nothing is retired or moved without the User's word.
