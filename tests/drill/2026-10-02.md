The rule that did the work, in every script now: write the file with one Write call and return; do not re-read, edit, count, or check it, because a checker runs next and names anything unmet. Both are in PR #14 with the post-rewrite check for `draft.js` and the validate-revise-validate loop for market research.

Two things learned on the way:

1. With the entry's source as `github`, the installer cloned over SSH and failed on GitHub's host key, because the Mac has no SSH setup; a Claude Code update did not change it. The entry now names the HTTPS git URL as a `url` source, which a public repository clones without credentials (`claude-plugins` 1.4.1).
2. A session started with `--plugin-dir` pointing at the Phase 0 spike plugin answered `/ck:next` from the spike, because the spike also calls itself `ck`. The installed plugin shows only in a session started without that flag.
