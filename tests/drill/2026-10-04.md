## What broke, and the fix in 0.1.3

1. **Draft over the cap.** River writes to the limit and lands over it. Fix: the length comes first in River's instructions, with a target of about 1,000 words under the 1,200 cap.
2. **No check after the revision.** The result said `valid: false` on a file that was fine. Fix: the validate, revise, validate loop from the team workflow, two revisions at most.
3. **No run record on a direct launch.** `.ck/runs/brief-latest`, run id `brief-direct`, and a placeholder date. Fix: `/ck:brief` is now a skill that mints the run and owns the review; the workflow is `ck:brief-draft`.
4. **Bold around code.** The page renderer split the line at code spans before looking for bold. Fix: code spans are lifted out first; test added.
5. **Stale cache** from the September drill (`.ck/runs/20260909T040516Z-brief`, a market file about lemonade-stand signs) deleted from the test project.

Not a bug, for the author's review: the brief says 22 persona profiles; the roster is 21.
